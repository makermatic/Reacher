# Reacher

Working name. The prototype was called Studio Outreach Tracker.

A Kitsu-style job-hunt tracker: companies with status chips, a company page with email chains, notes and interviews, and AI that turns plain-language updates into changes.

- `prototype/studio-outreach-tracker.html` is the working prototype. Open it in a browser to look around. It runs in preview mode outside claude.ai, so changes aren't saved and the AI features are off.
- `docs/SPEC.md` covers every feature, the data model and the decisions behind them.
- `CLAUDE.md` is the catch-up guide for Claude Code.
